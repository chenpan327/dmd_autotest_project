0. 全景图：飞控系统的知识地图

飞控系统（Autopilot）的本质是一个以数百赫兹闭环运行的状态反馈系统：传感器测量飞机的当前状态（姿态、位置、速度、空速），估计器把多源噪声测量融合成一致的状态估计，控制律把「期望状态与实际状态之差」换算成舵面偏转与油门，执行机构改变气动力从而改变飞机状态——如此循环，每秒重复数百次。整个飞控的知识体系分成五层：

 任务层     飞行模式状态机(commander) / 航点导航(navigator) / 起降逻辑 / 失控保护
 ─────────────────────────────────────────────────────────────────
 制导层     侧向制导(L1/NPFG: 位置误差 → 期望滚转)
            纵向制导(TECS: 高度/空速误差 → 期望俯仰 + 油门)
 ─────────────────────────────────────────────────────────────────
 控制层     姿态环(fw_att_control: 期望滚转/俯仰 → 期望角速率)
            角速率环(fw_rate_control: 角速率误差 → 舵面偏转, 最内层 P 控制)
 ─────────────────────────────────────────────────────────────────
 估计层     EKF2(四元数姿态 + 速度 + 位置 + 传感器偏差 + 风速, 24 状态)
            传感器驱动(sensors) / 标定(sensor_calibration) / 空速(airspeed)
 ─────────────────────────────────────────────────────────────────
 平台层     NuttX RTOS / uORB 消息总线 / 控制分配(control_allocator) / 混控
            MAVLink 遥测 / 日志(logger·ULog) / 参数系统 / 驱动(IMU·GPS·空速计)

固定翼与多旋翼的根本区别决定了控制架构的差异：多旋翼靠改变各电机转速矢量合成力（姿态即控制的全部），固定翼靠舵面改变气动力（姿态只是产生气动力的手段，空速是安全的底线）。固定翼必须回答两个多旋翼没有的问题：其一，侧向位置误差不能直接换算成侧向速度指令（飞机不能横着飞），必须经由「滚转产生向心力」的间接路径——这就是制导律（第 7 章 L1）的由来；其二，高度与空速通过俯仰角强耦合（拉杆升高度但减速），必须解耦——这就是总能量控制（第 7 章 TECS）的由来。

1. 坐标系与姿态数学：旋转矩阵、欧拉角与四元数

姿态（attitude）是「机体坐标系相对导航坐标系的旋转」，而旋转是整座飞控数学大厦的地基：EKF2 的状态量、控制器里的每一条指令、四元数微分方程的每一行代码，都建立在本章的推导之上。核心问题只有一个：如何无歧义、可计算、无数值陷阱地表示三维旋转。三种主流答案——方向余弦矩阵（DCM）、欧拉角、四元数——各有明确的数学性质与适用边界。

1.1 坐标系定义与记号约定

坐标系 记号 轴定义 用途
导航坐标系（NED） n 或 ⟨n⟩ North-East-Down：x 指北，y 指东，z 指地 位置/速度/风的世界坐标。z 向下使高度为负值，与重力方向一致，右手系自洽
机体系（FRD） b 或 ⟨b⟩ Front-Right-Down：x 指机头，y 指右翼，z 指机腹 IMU/舵面/气动力全部在此测量与建模。与 NED 同为右手系，两系只差一个旋转
气流坐标系 w x 指相对气流方向 升力/阻力定义在此（阻力沿气流，升力垂直气流）

姿态就是从 ⟨n⟩ 到 ⟨b⟩ 的旋转 Rn→b（或其逆 Rb→n）。PX4 全线采用 NED/FRD 约定（与航空传统一致，与 graphics/ROS 的 ENU/FLU 不同——做 ROS 集成时要显式转换）。角度记号：滚转 φ（绕机体系 x）、俯仰 θ（绕 y）、偏航 ψ（绕 z）；体轴角速率 p、q、r 分别对应绕 x、y、z。地速矢量 Vg（导航系测量）、空速矢量 Va（机体系气动速度）、风速矢量 Vw 满足风三角（第 2.5 节）。

1.2 旋转矩阵（DCM）：推导与三性质

方向余弦矩阵（Direction Cosine Matrix）的定义直接了当：R 的第 (i, j) 元 = 新坐标系的第 i 个单位轴在旧坐标系中的第 j 个分量。先推最基本的一块积木——绕 z 轴旋转 ψ 角。取机体 x 轴单位向量，它在导航系中的投影随偏航变化：

 机体 x 轴在旋转 ψ 后指向水平面内 (cosψ, sinψ, 0) 方向
 机体 y 轴 → (−sinψ, cosψ, 0)
 机体 z 轴 → (0, 0, 1)

 按定义逐列填入, 得绕 z 轴的旋转矩阵:
            ┌ cosψ  −sinψ   0 ┐
 Rz(ψ)  =   │ sinψ   cosψ   0 │      列 = 机体轴在导航系的投影
            └   0      0     1 ┘      (即"方向余弦"名称的由来)

 同理 Ry(θ) = ┌  cosθ   0   sinθ ┐     Rx(φ) = ┌ 1    0       0    ┐
              │    0    1    0   │             │ 0   cosφ   −sinφ  │
              └ −sinθ   0   cosθ ┘             └ 0   sinφ    cosφ  ┘

三块积木按「先滚转、再俯仰、后偏航」的次序复合（ZYX 欧拉序），得到从机体系到导航系的完整变换（FRD → NED）：

 R = Rz(ψ)·Ry(θ)·Rx(φ)

       ┌ cosψcosθ   cosψsinθsinφ − sinψcosθcosφ   cosψsinθcosφ + sinψcosθsinφ ┐
   =   │ sinψcosθ   sinψsinθsinφ + cosψcosθcosφ   sinψsinθcosφ − cosψcosθsinφ │
       └ −sinθ      cosθsinφ                        cosθcosφ                  ┘

 用途: 把机体系测量的量变换到导航系, 如加速度计测得的比力:
   a_nav = R · a_body − g·[0,0,1]ᵀ     (g 沿导航系 z 向下)
 这正是 EKF2 中把 IMU 数据从机体系搬进导航系的那一步。

旋转矩阵有三条数学性质，每条都对应工程上的一个事实：

  1. 正交性 RᵀR = I：旋转不改变长度与角度。工程含义：逆变换就是转置 R⁻¹ = Rᵀ，且不需要额外存储——PX4 的 matrix::Dcm 类利用这一点让正逆变换共享同一份数据。
  2. det(R) = +1：旋转是「保定向」的正交变换（det = −1 的正交阵含镜像反射，不是物理旋转）。工程含义：若算法输出 det ≈ −1，说明姿态解算翻转了，立即判故障。
  3. 乘法封闭，构成群 SO(3)：两个旋转的复合仍是旋转，R₂·R₁ = 「先做 1 再做 2」。工程含义：姿态更新可以用「当前姿态 ⊗ 微小旋转增量」递推，这正是四元数积分与 EKF 传播的骨架。注意矩阵乘法不可交换——先滚 90° 再俯仰 90°，与先俯仰再滚转结果不同；这解释了为什么大角度机动时欧拉角控制律会出现耦合误差（第 6.5 节）。

1.3 欧拉角：直观的代价是两处奇异

欧拉角用三个角度（ψ, θ, φ）描述旋转，是人类可读性最好的表示——地面站显示、日志回放、参数定义都用它。但它的数学缺陷必须刻在脑子里：

奇异点一：万向节锁（θ → ±90°）

九个矩阵元素只有三个自由度，三个欧拉角的取值域是 ψ∈(−180°,180°]、θ∈[−90°,90°]、φ∈(−180°,180°]。当 θ = ±90° 时，Rx 与 Rz 的旋转轴在空间中重合（滚转轴与偏航轴共线），此时 φ 与 ψ 单独变化无数种组合产生同一个姿态——表示退化。物理上飞机没出任何问题，只是「坐标」坏了：姿态环若直接用欧拉角反馈，飞机做过顶俯冲（θ 过 90°）瞬间控制器会读到跳变的 φ/ψ 而失控。这就是飞控内部状态一律用四元数、只在输出层才转欧拉角的原因。

奇异点二：欧拉角速率 ≠ 体轴角速率（1/cosθ 奇异）

陀螺测的 p、q、r 是体轴角速率；φ̇、θ̇、ψ̇ 是欧拉角时间变化率。两者不等——推导如下：体轴角速率矢量 ωb 是三次欧拉旋转角速度在机体系的矢量和。逐项投影：ψ̇ 绕导航 z 轴，向机体系投影需乘 R；θ̇ 绕「偏航后的 y′ 轴」；φ̇ 直接绕机体系 x 轴：

 ω_b = φ̇·[1,0,0]ᵀ + θ̇·R_x(φ)·[0,1,0]ᵀ + ψ̇·R_x(φ)·R_y(θ)·[0,0,1]ᵀ

        ┌ 1    0        −sinθ ┐   ┌ φ̇ ┐        ┌ p ┐
 ω_b =  │ 0  cosφ      sinφ   │ · │ θ̇ │   即   │ q │ = T·φ̇_euler
        └ 0  −sinφ     cosφ   │   └ ψ̇ ┘        └ r ┘   (T = 转换矩阵)

 反解 (注意 det(T) = cosθ, θ=±90° 时 T 不可逆 —— 第二处奇异):
        ┌        1         sinφ tanθ     cosφ tanθ ┐   ┌ p ┐        ┌ φ̇ ┐
 φ̇_e =  │        0         cosφ          −sinφ     │ · │ q │   即   │ θ̇ │ = T⁻¹·ω_b
        └        0         sinφ/cosθ      cosφ/cosθ ┘   └ r ┘        └ ψ̇ ┘

两个推论值得记住：其一，T 不是正交矩阵（列向量范数不为 1），所以「欧拉角变化率的模」不等于「旋转角速度的模」，绝不能拿 |φ̇| 当角速度用；其二，θ 接近 ±90° 时 1/cosθ → ∞，欧拉角微分方程病态——再次说明飞控内部传播必须用四元数。

1.4 四元数：四参数的完备旋转表示

定义与代数

四元数 q = q₀ + q₁i + q₂j + q₃k，常写成标量-矢量两段：q = (q₀, qv)，qv = (q₁, q₂, q₃)。虚数单位满足哈密顿规则 i² = j² = k² = ijk = −1（注意三个两两相乘还交换出负号：ij = k, jk = i, ki = j，而 ji = −k…）。由此定义四元数乘法（Grassmann/Hamilton 积）：

 q ⊗ p = ( q₀p₀ − q_v·p_v ,  q₀p_v + p₀q_v + q_v×p_v )
          └标量部分┘          └矢量部分(含叉积, 故乘法不可交换)┘

 伴随定义: 共轭 q* = (q₀, −q_v);  范数 ‖q‖ = √(q₀²+q₁²+q₂²+q₃²)
 单位四元数 ‖q‖=1 的全体构成三维球面 S³ —— 它是 SO(3) 的「双重覆盖」:
 q 与 −q 表示同一个旋转 (转 α 角与转 α−360° 角等价)。

四元数如何表达旋转：与 Rodrigues 公式的等价性

任何旋转都可以用「轴-角」表示：绕单位轴 n 转 α 角。把轴角打包成单位四元数：

 q = ( cos(α/2), sin(α/2)·n )           ← 半角! 这是四元数双倍覆盖的根源

 用 q 旋转矢量 v (把 v 塞进纯虚四元数 v̄=(0,v)):
   v̄′ = q ⊗ v̄ ⊗ q*          ← 左乘右旋, 中间夹住

 它与经典 Rodrigues 旋转公式完全等价:
   v′ = v·cosα + (n×v)·sinα + n(n·v)(1−cosα)
        └垂直分量转 α 角┘└轴向分量不变┘
 验证思路: 把 v 分解为平行于 n 的分量 (旋转下不动) 与垂直分量 (在垂直平面内转 α),
 展开四元数乘法逐项核对即得 —— 矢量部分的三重积 (q₀²−q_v·q_v)v + 2(q_v·v)q_v + 2q₀(q_v×v)
 恰好用半角公式 sinα=2sin(α/2)cos(α/2), 1−cosα=2sin²(α/2) 化回 Rodrigues 形式。

与 9 参数的 DCM 相比，四元数用 4 个参数（带 1 个归一化约束）就完备地覆盖了 SO(3)：没有奇异点（S³ 上处处光滑），不存在万向节锁，插值（slerp）与微分方程都简单。这是它成为飞控内部表示的根本原因。

姿态微分方程：q̇ = ½ q ⊗ ω 的推导

这是整个姿态估计环节最重要的公式。设飞机在一个采样周期 dt 内绕体轴转过微小角度 Δθ = ω·dt。微小旋转的四元数近似为 (1, Δθ/2)（半角的小角度近似：sin(Δθ/2) ≈ Δθ/2，cos ≈ 1）。姿态递推「旧姿态 ⊗ 增量」（体轴增量右乘）：

 q(t+dt) = q(t) ⊗ (1, ω·dt/2)
 展开: q(t+dt) − q(t) = (q(t) ⊗ (0, ω/2)) · dt
 取 dt→0:
        q̇ = ½ · q ⊗ ω_body          ← 体轴角速度(陀螺测量)右乘
 等价地, 若用导航系角速度 ω_nav:  q̇ = ½ · ω_nav ⊗ q   (左乘)

 PX4 EKF2 用其分量形式数值积分(梯形/四阶 Runge-Kutta), 并在每步后强制归一化 ‖q‖=1
 (浮点误差会让范数漂移; 归一化投影回 S³ 流形)。

误差四元数与姿态误差

控制与估计都需要回答「当前姿态离目标姿态差多少」。定义误差四元数 qe = qref⁻¹ ⊗ q（从目标系转到实际系的增量旋转）。当误差较小时：

 q_e ≈ ( 1, ½·δθ )      即 q_e 的矢量部分 ≈ 误差角矢量 δθ 的一半
 δθ 的方向 = 需要修正的旋转轴, |δθ| = 夹角 (小角度下)

这条性质是第 5 章「误差状态 EKF」与第 6 章姿态环的公共桥梁：四元数矢量部分在单位四元数附近就是「旋转变量的局部线性坐标」——姿态误差角天然地住在 q=1 附近的切空间里。EKF 的姿态状态误差直接取 q_e 矢量部分（3 维），姿态环的角速率指令直接由 δθ 除以时间常数生成。

2. 固定翼飞行力学：从气动力到运动方程

控制律设计的前提是知道「被控对象长什么样」。本章把飞机建模成受气动力的刚体，依次建立气动力模型 → 六自由度非线性方程 → 配平点线性化三级模型。最后一级的线性化模型是理解第 6、7 章所有控制参数的数学语言：增益怎么影响阻尼、振荡从哪个模态来，答案全在稳定性导数与特征值里。

2.1 气动力模型：动压、升力线与失速

固定翼的一切气动力都建立在一个标量上——动压 q̄（dynamic pressure，与控制理论的 Q 矩阵无关，注意区分）：

 q̄ = ½·ρ·V_a²          ρ: 空气密度(kg/m³, 海平面标准值 1.225), V_a: 空速(m/s)

 升力   L = q̄·S·C_L      阻力  D = q̄·S·C_D      S: 机翼参考面积
 俯仰力矩 M = q̄·S·c̄·C_m   c̄: 平均气动弦长

动压是「速度的二阶放大器」——这解释了固定翼控制的两个根本事实：其一，舵效与速度平方成正比，低速时舵面近乎失效（起飞阶段舵量要给大、增益要补偿）；其二，同样的迎角扰动，高速时产生的力矩是低速时的数倍，固定增益控制在不同速度下表现完全不同（PX4 用空速缩放 gain scheduling 解决，见 6.5 节）。

升力系数在失速前近似线性：

 C_L = C_L0 + C_Lα·α        α: 迎角(angle of attack)
 C_L0: 零迎角升力(带安装角/弯度翼型), 典型 0.1~0.3
 C_Lα: 升力线斜率, 典型 4~5 /rad (有限翼展, 理论最大 2π)
 失速: α > α_crit(典型 12°~16°) 时 C_L 崩塌, C_D 激增 → 掉高度且舵效骤降

俯仰力矩系数决定静稳定性（2.3 节的 Cmα）。PX4 内置了简化气动模型库 src/lib/fw_performance_model，把升阻极曲线（drag polar）参数化用于仿真与性能预测。

2.2 六自由度方程：旋转坐标系里的牛顿定律

在惯性系里牛顿定律是 F = d(mV)/dt。但传感器（IMU）与气动力都在旋转的机体系里测量与建模，必须把求导搬到旋转坐标系——这一搬就多出了著名的耦合项。设机体系以角速度 ω 旋转，任意矢量在旋转系中的导数满足 dA/dtinertial = ḊA/dtbody + ω×A。套到动量上（m 近似常量）：

 F = m·( V̇_b + ω×V_b )        ⟹   V̇_b = F/m − ω×V_b
                                  └气动力+推力+重力┘└旋转系假象力┘

逐分量展开（FRD 机体系，速度分量 u/前、v/右、w/下；力分量 X、Y、Z；重力在机体系的投影 g·(−sinθ, cosθsinφ, cosθcosφ)——注意与偏航 ψ 无关，机头转向不改变重力相对机体的方向）：

 平动三方程 (牛顿) ──────────────────────────────────────
 u̇ = rv − qw − g·sinθ     + X/m      X: 推力+阻力+轴向力
 v̇ = pw − ru + g·cosθ·sinφ + Y/m     Y: 侧力(侧滑与方向舵)
 ẇ = qu − pv + g·cosθ·cosφ + Z/m     Z: 升力为主(通常 z 向下为正)

 转动三方程 (角动量定理: M = Ḣ_b + ω×H,  H = I·ω)
 I_x·ṗ = L̄ + (I_y − I_z)·q·r        L̄: 副翼滚转力矩
 I_y·q̇ = M̄ + (I_z − I_x)·r·p        M̄: 升降舵俯仰力矩
 I_z·ṙ = N̄ + (I_x − I_y)·p·q        N̄: 方向舵偏航力矩

两个工程推论值得展开：其一，qw、rv 这类耦合项是小量——固定翼角速率典型只有零点几 rad/s，耦合项比气动项小两个数量级，控制器设计中普遍忽略，这是角速率环能用最简单 P 控制的底气（6.4 节）；其二，(I_y−I_z)qr 等「陀螺项」在大角速率机动（多旋翼翻滚、无人机暴力飞）时不可忽略，而固定翼横滚/俯仰角速率有限，故固定翼控制器不做角动量解耦，多旋翼控制器则要考虑。

2.3 小扰动线性化与稳定性导数

六自由度方程是非线性耦合的，直接用它设计控制律既无必要也无可能。标准做法：先求配平点（trim）——所有状态导数为零的定直飞行状态，再在配平点做一阶泰勒展开：

      Δẋ = A·Δx + B·Δu        A_ij = ∂(ẋ_i)/∂(x_j)|_trim ,  B_i = ∂(ẋ_i)/∂(u_i)|_trim

 固定翼的两组状态 (对称性使纵向与横航向近似解耦 —— 这是飞机构型对称送的礼物):
   纵向:   Δx = [Δu, Δw(或Δα), Δq, Δθ]ᵀ      输入: 升降舵 δe, 油门 δt
   横航向: Δx = [Δv(或Δβ), Δp, Δr, Δφ, Δψ]ᵀ   输入: 副翼 δa, 方向舵 δr

 A 矩阵的无量纲元素称"稳定性导数"(stability derivatives), 每个都有明确物理意义:
 ─────────────────────────────────────────────────────────────
 C_Lα    升力线斜率(升力对迎角的敏感度)
 C_mα    俯仰静稳定导数: 必须 < 0 (迎角增 → 低头恢复力矩)
 C_mq    俯仰阻尼导数: 必须 < 0 (俯仰角速率 → 阻尼力矩, 主要来自平尾)
 C_lp    滚转阻尼导数: 必须 < 0 (滚转速率 → 阻尼, 来自左右翼升力差)
 C_nβ    航向静稳定导数(风标效应): 必须 > 0 (侧滑 → 回正偏航力矩, 垂尾贡献)
 C_nr    偏航阻尼导数: 必须 < 0
 C_lβ    上反效应导数: 通常 < 0 (侧滑 → 滚转恢复, 机翼上反角贡献)
 ─────────────────────────────────────────────────────────────

把最重要的 Cmα 的物理来源说透：机翼升力集中作用于「焦点」（气动中心，通常在 1/4 弦长处）。迎角增大 → 升力增大 → 焦点处多出一个正升力。若重心在焦点之前，这个升力对重心形成低头力矩——迎角自己「刹车」，飞机静态稳定；若重心在焦点之后，迎角越飞越大直至失速——静态不稳定。整机配重（电池位置）直接决定这个条件，重心检查是固定翼首飞的第一道安全工序（第 9 章）。同理 Cnβ：侧滑使垂尾迎角变化，产生回正力矩——「风标效应」。

2.4 纵向两个特征模态：短周期与长周期起伏

对纵向 A 矩阵求特征值，几乎总是得到一对快根和一对慢根——对应两个经典模态。理解它们之后，调试时看到任何俯仰振荡都能立刻分类归因。

短周期（Short Period）——快模态，姿态环的战场

短周期中迎角与俯仰角速率快速交替，速度几乎不变（弹道来不及弯）。忽略升力引起的弹道变化，把俯仰动力学写成近似二阶：

 特征方程近似:  s² − M_q·s − M_α = 0        (M_α, M_q 均为负的无量纲导数)
                └阻尼项┘   └刚度项┘
 自然频率: ω_sp = √(−M_α)        阻尼比: ζ_sp = (−M_q) / (2·√(−M_α))

 物理读法: M_α 是"角刚度"(迎角偏差产生恢复力矩, 弹簧), M_q 是"角阻尼"(角速率产生阻尼力矩, 减振器)
 典型量级: ω_sp ≈ 2~6 rad/s (周期 1~3 s) —— 姿态环/角速率环的带宽必须显著高于它

长周期（Phugoid，起伏）——慢模态，TECS 的战场

长周期中迎角几乎不变，速度与高度缓慢交换动能与势能：速度增加 → 升力大于重力 → 缓慢爬升 → 爬升耗动能 → 速度回落 → 升力不足 → 缓慢下沉 → 下沉增速 → 循环。近似「定迎角、定推力、无阻力」时：

 ω_ph ≈ √2·g / V        (速度越快周期越长; V=20 m/s → ω≈0.69 rad/s, 周期约 9 s)
 阻尼极弱: ζ_ph ≈ C_D/(√2·C_L)   (数量级 0.05 → 要振好几个周期才衰减)

调试速判：周期 1~3 s 的俯仰振荡是短周期问题（查速率环/姿态环增益、舵机抖动、间隙）；周期 8~20 s 的缓慢起伏是长周期问题（查 TECS 参数 FW_T_TIME_CONST、FW_T_SPDWEIGHT，第 7.6 节）。两者调法完全不同，混着调永远调不好。

2.5 风三角：地速、空速与风速

三个速度矢量满足一个恒等式，所有导航与制导问题的「风」都从这里出发：

 V_g = V_a + V_w       (在导航系合成; 下标 g=ground 地速, a=air 空速, w=wind 风速)
 地速 V_g: GPS/多普勒直接测量 —— 决定"飞机实际去了哪" (导航闭环用这个)
 空速 V_a: 皮托管测量 —— 决定"升力/舵效/失速" (安全与气动用这个)
 风速 V_w: 两者之差, EKF2 作为 2 个增广状态在线估计 (第 5.4 节)

三个直接推论：其一，逆风/顺风改变地速但不改变升力（迎角与空速没变）——巡逻任务顺风段飞得快逆风段飞得慢是正常物理，不要用「地速快了」调油门；其二，侧风使地速方向偏离机头方向（偏流角 β_crab = arcsin(V_w⊥/V_a)），飞机必须偏一个「蟹形角」才能沿航迹飞——L1/NPFG 制导自动处理（7.3 节）；其三，阵风是空速阶跃 → 动压与升力平方级突变 → 高度/姿态瞬间扰动，这是低空飞行最危险的因素。

3. 传感器与标定数学：误差模型、椭球拟合与磁航向

EKF 的输入质量决定上限，而传感器标定决定输入质量。本章的数学主线是把「传感器系统性误差」参数化成有限个待定系数，再用最小二乘从测量数据中解出来——标定本质上就是一次参数估计问题。

3.1 IMU 误差模型

陀螺与加计的真实输出可写成：

 y_meas = S·T·( x_true + b(T_temp) ) + n
           │ │      │        │
           │ │      │        └ 白噪声 + 一阶马尔可夫过程(随机游走的根源)
           │ │      └ 零偏 bias: 随温度/时间漂移, 是姿态估计最需要对抗的误差
           │ └ 轴间失准/交叉耦合矩阵(近单位阵)
           └ 尺度因子误差(近对角阵)

 Allan 方差(双对数图)可把 n 拆解成成分:
   斜率 −½ 段 → 角度随机游走 (陀螺白噪声积分, Q 噪声参数依据)
   平台段   → 偏置稳定性 (不可再小的常值零偏)
   斜率 +½ 段 → 速率随机游走 (偏置缓慢漂移, EKF 把 bias 当状态跟踪的原因)

PX4 的应对体系：src/lib/sensor_calibration 管离线标定（scale/bias/旋转），src/modules/temperature_compensation 管温漂（分段多项式拟合），EKF2 把残余零偏当作滤波状态在线估计（5.4 节）——三层防线，一层比一层慢。

3.2 加计标定：椭球拟合的最小二乘推导

观测事实：传感器静止时测得的是当地重力矢量，模长恒为 g。考虑尺度误差 S 与零偏 b，测量值 a 满足

 (a − b)ᵀ·(S·Sᵀ)⁻¹·(a − b) = g²      ← 这是一个被"变形+平移"的球面 = 椭球面

 目标: 从一批任意朝向的静止测量 (a₁..a_N) 中解出 S 和 b

线性化是关键一步：令 W = (SSᵀ)⁻¹（对称正定，6 个独立元素）并把括号展开，把非线性问题变成 10 个未知量的线性问题：

 展开定义: aᵀ·W·a − 2·bᵀ·W·a + (bᵀ·W·b − g²) = 0
 引入新未知量:  w = W 的 6 个上三角元素 (w₁₁,w₂₂,w₃₃,w₁₂,w₁₃,w₂₃)
               β = −2·W·b  (3 个)
               c = bᵀ·W·b − g²  (1 个)
 得到线性方程 (每条静止数据一个方程):
   w₁₁ax² + w₂₂ay² + w₃₃az² + 2w₁₂axay + 2w₁₃axaz + 2w₂₃ayaz + βx·ax + βy·ay + βz·az + c = 0

 N 条数据 → N 个方程 → 普通(线性)最小二乘 A·θ = 0(齐次型, 归一化后求最小特征向量)
 回代: W = chol 上三角恢复 → S⁻¹ 由 Cholesky 分解得到;  b = −½·W⁻¹·β
 自检: 校准后所有静止样本 ‖(a−b) 换算‖ 的模长残差 RMS 应接近噪声水平(≈0.01~0.05 m/s²)

六面法（PX4 默认流程，QGC 引导六面放置）是上式的工程特例：假设轴间失准可忽略（W 取对角），每面单独给两个方程（+g 朝上、−g 朝下），6 次放置恰好解出 3 个尺度 + 3 个零偏。六面法简单可靠但不修正轴间失准；旋转拟合数据量更大时用完整椭球。PX4 实现：`src/lib/sensor_calibration/Accelerometer.cpp`，标定数据存参数（每 IMU 一组），EKF 使用时按传感器实例查找。

3.3 磁力计标定：硬磁软磁与倾斜补偿航向推导

误差来源的两分法

来源 数学性质 几何表现
硬磁（hard iron）：机体上恒定磁场（电机磁体、钢件剩磁） 常值偏移矢量 b 理想的磁场模长球面整体平移
软磁（soft iron）：软铁材料被地磁感应出二次磁场 线性变换矩阵 S（近对角+小交叉项） 球面畸变为椭球

于是「理想磁场模长恒等于当地地磁模长 H₀（约 0.25~0.65 高斯，随纬度变化）」变成：

 ‖S⁻¹·(m − b)‖ = H₀        与加计同构! 同一套 10 参数线性最小二乘直接套用
 校准动作: 让机体在空中画"尽可能满的球"(各轴均匀翻转旋转), 覆盖度不足时 PX4 拒绝标定结果
 实现: src/lib/sensor_calibration/Magnetometer.cpp

倾斜补偿磁航向公式完整推导

磁力计给出机体系磁场矢量 m = (mx, my, mz)。要得到偏航角，思路是把 m 从机体系旋到水平导航系，取水平分量算方位角。用第 1.3 节的 R = Rz(ψ)Ry(θ)Rx(φ)（b→n）：

 m_n = R·m_b     取水平分量 m_nx, m_ny (指北/指东的磁场投影)

 定义两个中间量 (把含 ψ 与不含 ψ 的项分开):
   A =  mx·cosθ + my·sinφ·sinθ + mz·cosφ·sinθ     (磁场"北向投影"的幅度)
   B =  my·cosφ − mz·sinφ                          (磁场"东向投影"的幅度)
 代入 R 的前两行并整理, m_nx = cosψ·A − sinψ·B,  m_ny = sinψ·A + cosψ·B
 用和角公式逆读: m_ny/m_nx = tan(ψ + atan2(B,A))   ⟹   ψ_mag = atan2(−B, A)

 最终公式 (FRD/NED 约定):
   ψ_mag = atan2( −(my·cosφ − mz·sinφ),  mx·cosθ + my·sinφ·sinθ + mz·cosφ·sinθ ) + D
                                                                              └磁偏角┘
 验证两个特例 (北半球, 磁场指北并下倾):
   φ=θ=0, 机头指北: mx>0, my≈0  → ψ=atan2(0,+)= 0      ✔
   φ=θ=0, 机头指东: 磁北在机体 −y 方向 → my<0 → ψ=atan2(+,0)= +90°  ✔ (NED 东为正)

注意这个公式的适用条件：它假设磁力计只测地磁。机体内电机通电后的杂散磁场直接破坏 b 的常值假设——所以 PX4 做磁校准时要求上电静置检测环境场，飞行中 EKF2 用「磁场一致性检查」（磁强计读数与 EKF 已估计的地磁矢量残差超 χ² 门限即拒绝该源，见 5.7 节）在线防干扰。磁偏角 D 由世界地磁模型（src/lib/world_magnetic_model，WMM）按经纬度查表给出，不补偿的话航向会有全球范围 ±(0~30)° 的系统差。

3.4 气压高度：国际标准大气推导

气压计测的是静压 p，高度由大气模型反演。两层假设：静力学平衡 dp = −ρ·g·dh，理想气体 ρ = p/(R·T)；对流层内温度线性递减 T = T₀ − L·h（国际标准大气：T₀ = 288.15 K，L = 6.5 K/km，p₀ = 101325 Pa，R = 287.05 J/(kg·K)）。代入积分：

 dp/p = −(g/(R·T))·dh,  T = T₀ − L·h
 ⟹ p = p₀·(T/T₀)^{g/(L·R)}        指数 g/(L·R) = 5.2559 (无量纲)
 反解高度:
        h = (T₀/L)·[ 1 − (p/p₀)^{L·R/g} ]        L·R/g = 0.19026
 数值手感: 每 100 m ≈ 12 hPa (1200 Pa);  反向 1 hPa ≈ 8.4 m

工程三要点：其一，模型假设的是「标准大气」，实际天气使同一高度气压漂移可达数十 hPa——所以 PX4 用 GPS 高度或起飞点气压做基准（气压只提供相对高度与爬升率）；其二，气流效应：高速飞行时机体附近动压抬升使静压测量偏低、高度偏高，需要空速相关的补偿；其三，噪声约 ±10 Pa（±0.8 m）且随高度有低频漂移，EKF 中作为高度观测（噪声按数据手册 + 飞行动态放大）。

3.5 空速测量与等效空速

 皮托-静压系统: 测总压 p_t 与静压 p_s 之差 Δp = q̄ = ½ρ·V²   (伯努利, 不可压假设)
 真空速 TAS = √(2·Δp/ρ)         ρ 用实测气压+温度计算
 等效空速 EAS = TAS·√(ρ/ρ₀)     (把当前密度折算回海平面标准密度的速度)

 PX4 内部 (TECS/制导/参数) 统一使用 EAS: 同一 EAS 对应同一动压 → 同一升力/舵效,
 高度变化带来的气动差异被"吸收"进 TAS 与 EAS 之比, 控制参数跨高度保持一致。

空速计的失效模式必须列入检查清单：管路漏气/打折（读数恒偏）、结冰（读数冻结或飞涨）、动压孔堵塞（Δp→0）、位置误差（安装点气流畸变，随迎角变化）。EKF2 与 airspeed_selector 模块做在线一致性检查：空速与地速+风速估计矛盾、或与气压高度变化率矛盾时，自动降级为「无空速传感器模式」（TECS 用油门/姿态推算空速，见 7.6 节）。

3.6 时间戳与采样同步

一个容易被忽略但对 EKF 精度影响巨大的细节：所有测量必须带上正确的采样时间戳。IMU 以 2~8 kHz 采样、GPS 以 5~10 Hz 到达且自带 50~200 ms 的传输延迟、空速计管路有气动延迟——EKF 按「事件发生时刻」把每个测量对齐到统一时间轴，时间戳错 10 ms 在 30°/s 的机动下就是 0.3° 的姿态系统差。PX4 的做法：驱动在读取瞬间打时间戳（有硬件时间戳的 IMU 用传感器自身时钟），EKF2 内部维护「测量缓冲队列 + 时间对齐器」，GPS 到达时按其时间戳回溯匹配 IMU 状态。时间戳混乱的典型症状：静态很好、机动时姿态滞后或「先动后测」，日志里 innovation 波形与机动波形错位。

4. 状态估计 Ⅰ：互补滤波与姿态估计原理

姿态估计要回答「飞机现在什么姿势」。单独任何一颗传感器都答不好：陀螺动态好但漂移，加计长期准但机动中失效。互补滤波用一条极简的频域思想把两者「取长补短」地缝起来——它不深，但把「为什么需要卡尔曼滤波」「滤波器在频率上各管一段」这两个直觉训练到最好，是理解 EKF 的最佳前菜。

4.1 各传感器的互补特性

传感器 短期（高频） 长期（直流） 失效模式
陀螺仪 好：噪声小、带宽高，积分得角度变化 坏：零偏导致积分漂移（0.5°/min 的零偏 1 小时漂 30°） 漂移、温漂、振动饱和
加速度计 坏：噪声大，且混入平动加速度（机动时测的不是重力！） 好：长期指向重力方向，提供绝对「水平」基准 机动污染、振动敏感
磁力计 坏：噪声大、易受电机干扰 好：长期指向地磁北，提供绝对偏航基准 磁场干扰、地磁模型误差

结论一目了然：高频信陀螺（积分），低频信加计/磁力计（修正）。互补滤波就是把这句话翻译成传递函数。

4.2 频域互补性推导

设 θg(s) 为陀螺积分给出的角度（含漂移误差，慢变），θa(s) 为加计给出的角度（含噪声，快变）。取「陀螺走高通、加计走低通」再相加：

    ŝ(s) = [ s/(s+ωc) ]·θ_g(s)  +  [ ωc/(s+ωc) ]·θ_a(s)
              └高通: 快变通过┘      └低通: 慢变通过┘

 关键: 两个滤波器互补 —— 高通 + 低通 = 恒等:
    s/(s+ωc) + ωc/(s+ωc) = (s+ωc)/(s+ωc) = 1

 ⟹ 若 θ_g 与 θ_a 携带同一真值信号 θ, 则 ŝ(s) = [1]·θ(s) + (漂移/噪声误差项被滤掉)
 即: 信号分量完整保留(不引入相位/幅值畸变), 陀螺的零偏(直流误差)被高通切除,
    加计的高频噪声被低通压平 —— 各拿各的长处, 交接频率 ωc 两侧平滑过渡。

4.3 离散实现与 α 系数

一阶低通 ωc/(s+ωc) = 1/(τs+1)（τ = 1/ωc）用后向欧拉离散得 y[k] = (1−α)y[k−1] + α·x[k]，其中 α = dt/(τ+dt)。于是经典的互补滤波递推：

 预测:   θ_pred = θ_prev + ω_gyro·dt              (陀螺积分, 高频主干)
 修正:   θ = α·θ_pred + (1−α)·θ_acc                (加计低频锚定)
 等价的比例反馈形式 (把修正项看成"误差的比例补偿"):
    e = θ_acc − θ_pred
    θ = θ_pred + (1−α)·e = θ_pred + K·e,   K = 1−α = τ⁻¹ 意义下的增益
 这个形式直接推广成矢量/四元数版 —— 即 Mahony 滤波 (4.4 节)。

4.4 Mahony 滤波：误差叉积的几何意义

Mahony 滤波把「角度误差」推广为「旋转误差」：用测得的参考方向与预测的参考方向的叉积作为姿态误差信号，通过 PI 反馈同时修正姿态与陀螺零偏。推导叉积为什么就是误差：

 参考方向: 导航系重力单位矢量 ḡ = [0,0,−1]ᵀ (向下)
 预测值:   v_pred = Rᵀ·ḡ          (当前姿态估计把重力转进机体系)
 测量值:   v_meas = a/‖a‖         (加计读数归一化)
 设真实姿态误差为小角 δθ (绕轴 δθ 转动):  v_meas ≈ v_pred + δθ×v_pred
 则:  e = v_meas × v_pred ≈ (v_pred + δθ×v_pred) × v_pred
        = v_pred×v_pred + (δθ×v_pred)×v_pred = δθ·(v_pred·v_pred) − v_pred·(δθ·v_pred)
        ≈ δθ                              (单位矢量 + 小角近似下正交分量保留)
 ⟹ 叉积误差矢量 e 的方向 = 需要修正的旋转轴, 模长 = 误差角的正弦 ≈ 误差角

 反馈律 (PI):
    ω_bias ← ω_bias − Ki·e·dt        (积分项估计陀螺零偏, 慢速收敛)
    ω_used = ω_gyro − ω_bias + Kp·e  (比例项即时纠姿)
    q̇ = ½·q⊗ω_used → 数值积分并归一化 (第 1.4 节微分方程)

PX4 中的实现是 src/modules/attitude_estimator_q（Mahony 风格四元数估计器），可作为 EKF2 的备份估计器。它的适用边界要清楚：该公式假设加速度计测的就是重力——固定翼转弯时向心加速度、爬升时推力分量都会「伪装成重力」，直接融合会得到错误水平基准。工程做法是加速信任门：仅当 ‖a‖ ≈ g（误差 < 0.2g）且角速率不太大时才做修正，否则本周期只信陀螺。

4.5 一阶低通（PT1）与陷波滤波

互补滤波的本质构件是一阶低通（PX4 参数名里大量出现的 _FILTER 多为 PT1）：

 连续: G(s) = 1/(τs+1)      截止频率 f_c = 1/(2πτ), 该处幅值 −3 dB, 相位滞后 −45°
 离散: y[k] = (1−α)·y[k−1] + α·x[k],   α = dt/(τ+dt)   (后向欧拉, 无条件稳定)
 工程含义: 每升高一倍频程幅值衰减 6 dB(20 dB/dec), 相位滞后渐近 −90°
 代价: 一切滤波都是"拿相位换噪声" —— 反馈回路中过度滤波会吃掉相位裕度导致振荡

当振动是已知窄带频率（电机桨频、机架共振），PT1 全带宽压制代价太大，改用陷波滤波器（notch）：在极窄频段深挖一个坑，其余频段几乎透明：

 H(s) = (s² + ω₀²) / (s² + 2ζω₀s + ω₀²)      分子零点对在 ±jω₀ → 在 ω₀ 处幅值深衰减
 中心频率 ω₀(陷波点), 阻尼 ζ 控制坑宽(品质因数 Q = 1/2ζ)
 PX4 的陀螺滤波链: PT1(FW_GYRO_FILTER / 调参首站) + 一组可调陷波器
   + gyro_fft 模块: 对陀螺数据在线做 FFT 频谱分析, 自动定位机架共振峰并驱动陷波器跟频
     (自动陷波对振动自适应; 固定翼主要作用于桨频/结构模态, 多旋翼收益最大)

5. 状态估计 Ⅱ：卡尔曼滤波与 EKF2 数学原理

卡尔曼滤波是「带不确定性账本的加权平均」：它维护状态的估计值 x̂ 和估计的置信度（协方差 P），预测时账本越记越糊涂（P 变大），测量时按「谁的方差小信谁多」的比例修正（P 变小）。本章从一维情形完整推导出全部公式，再推广到非线性与姿态流形，最后落到 PX4 EKF2 的 24 状态结构。

5.1 卡尔曼滤波完整推导：从两个高斯的融合开始

问题：状态 x 的先验估计是高斯 N(x̂⁻, p⁻)（预测结果，方差 p⁻），新测量 y = x + n，n ~ N(0, r)。两个高斯的乘积仍是高斯——把后验概率 ∝ 先验 × 似然展开，对 x 求极小化 −2ln(后验)（等价于加权最小二乘）：

 J(x) = (x−x̂⁻)²/p⁻ + (y−x)²/r        ← "离预测的加权距离 + 离测量的加权距离"
 dJ/dx = 2(x−x̂⁻)/p⁻ − 2(y−x)/r = 0
 ⟹ x̂ = (r·x̂⁻ + p⁻·y)/(p⁻ + r) = x̂⁻ + [p⁻/(p⁻+r)]·(y − x̂⁻)
                                      └──────┬──────┘
 后验方差: 1/p = 1/p⁻ + 1/r  ⟹  p = p⁻·r/(p⁻+r)      定义 K = p⁻/(p⁻+r)   └ K·新息 ┘

一维结论就是全部 KF 的种子：增益 K = 先验方差/(先验方差+测量方差)，K∈(0,1)，天然实现「不确定性加权」——p⁻ 大（预测没把握）则 K→1 全信测量，r 大（测量噪声大）则 K→0 全信预测。写成多维形式（矢量状态 x，线性测量 y = Hx + n）：

 ═══ 预测(时间更新): 把状态沿过程模型推进, 账本变糊涂 ═══
    x̂⁻ = F·x̂                 F: 状态转移矩阵
    P⁻ = F·P·Fᵀ + Q           推导: 误差传播 δx⁻ = F·δx + w, w~N(0,Q) 与 δx 独立
                              Cov(δx⁻) = F·Cov(δx)·Fᵀ + Cov(w)
 ═══ 更新(测量更新): 用新息修正, 账本变清晰 ═══
    新息   ν = y − H·x̂⁻                        (测量与预测的差)
    K    = P⁻·Hᵀ·(H·P⁻·Hᵀ + R)⁻¹              (多维版增益, R: 测量噪声协方差)
    x̂   = x̂⁻ + K·ν
    P   = (I − K·H)·P⁻
 几何直觉: ν 张在"测量空间", K 是把 ν 投影回状态空间的"换算比";
 P⁻ 与 R 的相对大小决定每个方向上信谁 —— 与一维 K 完全同构。

5.2 一维数值走查

用气压高度跟踪走一遍，看「先信谁」如何随账本演化。测量噪声 r = 1 m²，初始 P = 1000（几乎无先验），x̂ = 0：

 k=1:  ν = 2 − 0 = 2    K = 1000/(1000+1) ≈ 0.999  → x̂ = 0 + 0.999×2 ≈ 2.00   P ≈ 1.0
 k=2:  ν = 3 − 2 = 1    K = 1/(1+1)       = 0.5    → x̂ = 2 + 0.5×1   = 2.50   P = 0.5
 k=3:  ν = 2 − 2.5 = −0.5  K = 0.5/(0.5+1) = 0.333 → x̂ = 2.5 − 0.167 ≈ 2.33  P ≈ 0.33
 k=4:  ν = 2 − 2.33 = −0.33 K = 0.33/1.33 ≈ 0.25 → x̂ ≈ 2.25              P ≈ 0.25
 …  K → p/(p+1) 单调下降, 估计值趋于测量均值, 且永远不再"全信"单次测量。
 第一帧几乎全信测量(K≈1), 之后逐渐"自信"——这就是滤波器的学习过程。

5.3 扩展卡尔曼滤波（EKF）：非线性世界的妥协

真实飞控的过程与观测模型都非线性（四元数微分方程、三角测量几何），KF 的线性假设失效。EKF 的做法朴素而有效：在当前估计点做一阶泰勒展开，用雅可比矩阵代替 F 和 H：

    x̂⁻ = f(x̂)                          (真实非线性模型传播名义状态)
    F  = ∂f/∂x |_{x̂}                    (该点的局部线性化)
    H  = ∂h/∂x |_{x̂⁻}
 其余公式与 KF 完全相同。
 局限: ①线性化点随估计漂移, 误差大时展开失真 → 可能发散; ②二阶以上项被丢弃;
 ③对"必须保持约束的状态"(如单位四元数)直接线性高斯建模会破坏约束。
 这三条局限正是"误差状态 EKF"要解决的问题。

5.4 误差状态 EKF（ES-EKF）：姿态住在流形上

姿态是三维流形 SO(3) 上的点，四元数是它 4 维的嵌入表示（带单位范数约束）。「高斯分布 + 线性变换」定义在向量空间上，硬套在姿态上会出现根本矛盾：高斯噪声加上去之后 ‖q‖≠1，约束被破坏；欧拉角参数化又有奇异点。误差状态 EKF 的解法是把状态拆成两层：

 ═══ 双层结构 ═══
 名义状态 x̂ (非线性传播, 保持所有约束):
    姿态: q̂ ← q̂ ⊗ exp([ (ω−b_g)·dt ]ₓ/2)     四元数微分方程的积分(流形上的"直线")
    速度/位置: 非线性动力学积分
 误差状态 δx (线性高斯 KF, 定义在切空间):
    δx = [ δθ(3) | δv(3) | δp(3) | δb_g(3) | δb_a(3) | δm_I(3) | δm_B(3) | δw(2) ]ᵀ = 23 维
    (名义四元数 4 维 + 误差 23 维 = EKF2 总计 24 个状态分量)
    δθ 正是第 1.4 节的误差四元数矢量部分: q = q̂ ⊗ δq, δq ≈ [1, δθ/2]

 传播:  δx⁻ = F·δx,  P⁻ = F·P·Fᵀ + Q      (线性, 雅可比 F 随名义状态更新)
 更新:  常规 KF 公式, 但测量模型用名义状态计算, 误差注入为流形运算:
    x̂ ← x̂ ⊞ δx     即: q̂ ← q̂⊗δq 归一化; v̂←v̂+δv; … (⊞ 称"盒加法")
    δx ← 0        (误差已吸收进名义状态, 账本清零, 但 P 不清零!)

三条收益对应三个数学事实：其一，误差 δθ 是小量，其线性化与高斯近似在切空间中始终有效（不存在远离线性化点的问题）；其二，名义状态永远满足单位四元数约束（乘法封闭性，1.2 节性质 3）；其三，雅可比在 δx=0 处求值，形式简洁（姿态误差对陀螺零偏的耦合块就是 −R[ω×] 与 −R 等 3×3 块）——这正是 PX4 EKF 源码里 PredictCovariance 的构造逻辑。

5.6 新息一致性检查：滤波器的免疫系统

EKF2 对每个测量做统计学体检。高斯假设下，标准化新息服从已知分布：

 ν = y − H·x̂⁻                 新息(残差)
 S = H·P⁻·Hᵀ + R              新息协方差(测量不确定性 + 预测不确定性)
 νᵀ·S⁻¹·ν ~ χ²(N)             N = 测量维数 (检验统计量)
 门限: νᵀS⁻¹ν > χ²_{1−α}(N)  ⟹ 拒绝本帧该测量 (α 通常取 1%~5%)
 连续多次超限 ⟹ 判定该传感器故障 ⟹ 数据源级降级/切换

这套 χ² 门限就是地面站里「EKF 检查」项的数学内核：磁力计被干扰、GPS 反射多径、气压计气流扰动，都会表现为新息统计量暴增而被挡在滤波器外——滤波器免疫的是「说谎的测量」，代价是故障期间状态纯预测传播（P 越来越大）。日志分析（Flight Review 的 innovation 曲线）看的就是这组量：新息应在门限内白噪声状，出现系统性偏置即说明模型或传感器有结构误差。

6. 控制理论 Ⅰ：级联 PID 与固定翼姿态控制

PID 是飞控最内层的肌肉。它简单到几乎不需要介绍，但「什么场合用 P、什么场合必须加 I、D 何时帮倒忙、饱和时积分怎么办」这套工程判断，决定了调参的成败。本章先给 PID 三个环节的频域本质，再讲数字实现的两个关键机制（微分滤波、抗积分饱和），最后沿 PX4 固定翼控制链从外到内走一遍。

6.1 PID 三环节的频域本质

环节 时域作用 频域性质 代价与适用
P（比例） 误差越大推力越大——提供恢复力 提高刚度与带宽（ω_n ∝ √Kp），消耗相位裕度 过大 → 高频振荡（相位损失 + 舵机延迟）
I（积分） 累积误差直到消除——消灭稳态误差与常值扰动 在积分频率以下增加 +90° 相位滞后、降低系统类型以上的低频刚度 引起超调与积分饱和（6.2 节）；只用于有常值扰动的通道（配平、风）
D（微分） 按误差变化率提前刹车——提供阻尼 +90° 相位超前（物理上是「预测」），但放大高频噪声 必须配合低通；噪声大的信号（加速度微分）慎用

经典取舍在固定翼上的体现：角速率环常只用 P——因为气动力本身自带阻尼导数（Clp、Cmq，2.3 节），舵面力矩与阻尼力矩已经构成阻尼够用的二阶环，再加 D 反而放大陀螺噪声；姿态环用 P（误差→角速率指令）；积分项集中在「有常值扰动」的地方——配平误差、不对称气动，如 TECS 的油门/俯仰 PI、姿态环的 I 只对误差缓慢累积并限幅。

6.2 数字实现的三个关键机制

（1）微分项滤波与「对测量微分」

理想 D = Kd·ė 对噪声增益无上限（微分放大高频）。标准做法是「带滤波的微分」：传函 Kds/(1 + s·τd)，τd 取采样周期的几倍~几十倍；并且对测量而非误差微分（D on measurement）——设定值阶跃时误差微分产生巨大尖峰，而测量微分只反映真实运动。

（2）抗积分饱和（Anti-windup）：back-calculation

问题：大误差期间积分持续累积，而执行器早已饱和——积到天上去的量（windup）在误差反向后要花很久「吐出来」，表现为大超调。解决：积分只积累「实际起作用」的部分：

 u_raw  = P + I + D            (未饱和计算输出)
 u_sat  = constrain(u_raw, u_min, u_max)
 I ← I + Ki·e·dt + (u_sat − u_raw)/T_t · dt
                      └反算项: 按时间常数 T_t 把"饱和掉的部分"从积分里扣回
 T_t 调节退饱和速度: 过小≈直接限幅(慢通道仍可能滞留), 过大≈无抗饱和
 PX4 实现: src/lib/pid (PID 类含 back-calculation 与限幅), 姿态/速率/TECS 全部使用

（3）dt 与采样周期

离散 PID 的 I 与 D 都显式含 dt：I += Ki·e·dt，D = Kd·(e[k]−e[k−1])/dt。控制频率必须稳定（定时器驱动而非主循环节奏），频率抖动直接变成增益抖动——这就是为什么 PX4 把控制环放在独立的定时驱动任务里而不是「哪里有空哪里跑」。

6.3 级联结构与带宽分离原则

 位置/航迹(L1·TECS)  ──►  姿态环  ──►  角速率环  ──►  舵机/油门
  ω₁ (~0.1-1 rad/s)      ω₂ (~2-6)      ω₃ (~10-30 rad/s)
  慢 ──────────────────────────────────────────► 快
 带宽分离: ω₃ ≥ 3~5·ω₂,  ω₂ ≥ 3~5·ω₁
 道理: 外环把内环视为"理想执行器"(瞬时跟踪指令), 这要求内环远快于外环;
 否则内外环相互耦合, 单环调参会互相抵消 —— 调参永远从最内环开始。

固定翼的实际链条（源码 src/modules/）：navigator（任务）→ fw_lateral_longitudinal_control（L1/NPFG + TECS，输出期望滚转 φsp、期望俯仰 θsp、油门）→ fw_att_control（姿态环，输出期望角速率 p/q/rsp）→ fw_rate_control（角速率环，输出三轴舵量）→ control_allocator（分配到舵机）。

6.4 姿态环：从角度误差到角速率指令

姿态环的数学极简——「误差角除以期望收敛时间」：期望在 τatt 秒内消掉 φ 误差，则需要的平均滚转角速率 psp = φerr/τatt。比例增益 K = 1/τatt 就是带宽。误差角正是第 1.4 节的误差四元数矢量部分——控制与估计在数学上共享同一个「切空间误差」概念。

固定翼特有的三件事：

  1. 偏航阻尼器（yaw damper）：滚转诱导侧滑 → 荷兰滚模态（横航向的耦合振荡，来自 Clβ 与 Cnβ 的竞合）。方向舵按 −Kr·r 或侧滑估计反馈阻尼。荷兰滚的特征是「机头左右摆 + 机翼轻微摇晃交替出现」，调方向舵阻尼参数改善。
  2. 协调转弯的升力补偿：滚转 φ 后升力垂直分量 L·cosφ < 重力，必须增大迎角补足——等效抬头量 Δθ ≈ (1/cosφ − 1)·(W/(q̄S·CLα))，工程上按 FW_ 参数随滚转角注入。极限提示：φ→90° 时 cosφ→0，任何迎角都补不回来，所以大坡度转弯必须配合增速（升力 ∝ V²）。
  3. 配平（trim）与前馈：舵量 = 配平值 + 反馈量 + 前馈。固定翼的俯仰配平随速度/载荷/构型连续变化，靠反馈 I 项慢速跟踪太迟钝——TECS 用能量误差的积分直接驱动配平（7.5 节），这是固定翼与多旋翼控制结构最实质的差别之一。

6.5 角速率环、空速缩放与舵效

最内环把角速率误差换算成舵偏：δ = Kp·(ωsp − ω) + trim。关键在 Kp 的时变：舵面力矩 ∝ 动压 ∝ V²，若 Kp 恒定，则同一角速率误差在低速（起飞/失速边缘）时舵效不足、在高速时增益过倍振荡。解法是空速缩放（gain scheduling）：输出乘以 (Vtrim/Va)² 的修正（以配平空速为 1），使闭环等效增益与速度解耦。无空速传感器时用油门近似推算动压。这也是固定翼「低速保护」的物理根源之一：空速太低时舵效缩水 + 升力不足，控制器再努力也无力回天——失速防护必须在能量层（TECS 限制 FWT_SINK_MAX/CLMB_MAX）而不是靠内环硬拉。

6.6 自动调参：系统辨识与频域设计

手工调参的经验法则（先内后外、每次一个参数、看振荡定增益）可以自动化：PX4 的 fw_autotune_attitude_control + system_identification + pid_design 三个库组成闭环：注入激励信号（PRBS/正弦扫频）→ 在线辨识舵量到角速率的频率响应 → 按目标相位裕度/带宽自动计算增益 → 平滑加载。数学内核是频域辨识（输入输出互谱/相关法估计频响函数）与经典回路成型（相位裕度约束下的增益选择）。固定翼使用要点：在平稳大气、中速巡航、高度余量充足时进行；调参对象是滚转/俯仰/偏航三通道的速率环增益。

7. 控制理论 Ⅱ：L1 制导与 TECS 总能量控制

固定翼控制链最外层的两个核心算法：L1/NPFG 解决「侧向怎么沿航迹飞」（位置误差 → 期望滚转），TECS 解决「纵向高度与空速怎么同时跟踪」（误差 → 俯仰 + 油门）。两者都是专为固定翼的间接控制路径设计的非线性方法——本章把它们的推导完整走一遍。

7.1 为什么不能直接用位置 PID

位置误差 e 经「滚转 → 向心加速度 → 航迹角变化 → 位置」作用，内部含两次积分（加速度→速度→位置）。纯 P 反馈的回路传函近似 e → a = K·e → 位置 = K·e/s²——特征方程 s² + K = 0 的根在虚轴上，临界无阻尼：飞机将永远沿航迹两侧等幅蛇形。必须引入「产生带阻尼的期望加速度」的制导律——L1 就是这样一个几何构造。

7.2 L1 制导律的几何推导

构造：在期望航迹上取「前方 L1 距离处」的参考点 P₁，从当前位置 P 看 P₁ 的连线与地速方向夹角 η。几何断言：飞机沿一段圆弧恰好飞到 P₁，该圆弧在 P 处与速度方向相切、在 P₁ 处与航迹相切——由对称性，弦 P→P₁ 所对圆心角为 2η：

 圆弧几何: 弦长 = 2·R·sin(η)      (弦与圆心角的关系, 圆心角=2η)
 ⟹  L1 = 2·R·sin(η)              R: 假想圆弧半径
 所需向心加速度(匀速圆周):
    a_s = V_g²/R = 2·V_g²·sin(η)/L1        方向: 垂直于地速、指向 P₁ 一侧
 期望滚转(向心加速度由升力的水平分量提供):
    φ_sp = atan( a_s / g ) ≈ a_s / g       (小坡度近似)
    └ 升力水平分量 L·sinφ 提供向心力, 垂直分量 L·cosφ 平衡重力 ┘

7.3 闭环性质：完整线性化推导 ω_n 与 ζ

L1 最漂亮的结果是：这个看似经验的几何律，闭环后恰是固定阻尼比 1/√2 的二阶系统，且带宽与速度成正比。推导只用到运动学（局部坐标：x 沿航迹，y 向左为正，航向偏差 ψ̃ = 航迹角 − 航向角）：

 ① 侧偏动力学:      ẏ = V·sin(ψ̃) ≈ V·ψ̃
 ② L1 向量与航迹夹角: η₂ = asin(−y/L₁) ≈ −y/L₁     (y<0 右偏时 L₁ 点在左前)
 ③ L1 定义的角度:    η = ψ̃ + η₂ = ψ̃ − y/L₁
 ④ 制导律:           a = 2V²·sin(η)/L₁ ≈ (2V²/L₁)·(ψ̃ − y/L₁)
 ⑤ 运动学:           ψ̃̇ = −χ̇ = −a/V = −(2V/L₁)·ψ̃ + (2V/L₁²)·y
 ⑥ 代入 ψ̃ = ẏ/V:
        ÿ = V·ψ̃̇ = −(2V/L₁)·ẏ + (2V²/L₁²)·y
 ⟹   ÿ + (2V/L₁)·ẏ + (2V²/L₁²)·y = 0        ← 干净的二阶! 特征方程对照 s²+2ζωₙs+ωₙ²:

        ω_n = √2·V/L₁        ζ = 1/√2 ≈ 0.707     ← 恒定最佳阻尼, 与速度无关!

 读出三个工程事实:
 · 带宽 ∝ V/L₁: 飞得越快, 同样的 L₁ 相对更"短"→响应更快 —— 几何律自动完成了速度调度
 · 调 FW_L1_PERIOD 即调 ω_n (名义周期 T = 2π/ωₙ = √2π·L₁/V):
     蛇形/振荡 → 增大 period; 切航点转弯迟钝、风中超调 → 减小 period
 · 阻尼比固定 0.707 是"每次都调到最优"的意思 —— 制导参数只剩一个, 这是 L1 流行的根本原因

7.4 边界与 NPFG 的改进

L1 的短板在强风与低速：地速 Vg 接近零（悬停顶风）时 ω_n → 0 但所需滚转不消失，且基于 L₁ = f(FW_L1_PERIOD·Vg) 的距离在逆风时缩短，增益剧烈变化；侧风大时地速矢量方向与机头严重分离，η 角的定义开始失真。PX4 v1.13 起引入 NPFG（New Path Following Controller，src/lib/npfg）替代经典 L1：以「航迹方位角变化率（bearing rate）」为被控量，显式使用风速估计构造无风等效坐标系，在风下保持阻尼与滚转限幅，并支持最小地速/爬升坡度约束。固定翼默认启用 NPFG，参数 FW_NPFG_* 与旧 FW_L1_* 概念对应（period/阻尼思想一脉相承）。

7.5 TECS 总能量控制系统的推导

问题陈述：固定翼只有一个直接「能量源」（油门→推力）和一个「能量转换器」（升降舵→弹道）。高度误差与空速误差通过俯仰强耦合：拉杆升高度但减速，推杆增速但掉高度。把两个误差各配一个 PID 互相打架（经典调参灾难）。TECS（Total Energy Control System）用能量观点一次解决——它是 PX4 固定翼纵向控制的唯一纵向框架（src/lib/tecs，作者 Paul Riseborough 的设计文档是最佳延伸阅读）。

 第一步: 把飞行状态写成能量
    比总能量(单位质量):  E/m = ½·V² + g·h        (动能 + 势能)
    总能量变化率:        Ė/m = V·V̇ + g·ḣ

 第二步: 力学恒等式给出"谁在供能"
    沿航迹方向牛顿定律:  m·V̇ = T − D − m·g·sin(γ)     (γ: 航迹倾角, ḣ = V·sinγ)
    两边乘 V/m:          V·V̇ = (T−D)·V/m − g·ḣ
    移项:                Ė/m = V·V̇ + g·ḣ = (T−D)·V/m
                          └───┬───┘   └──┬──┘
                        动能率+势能率    推力净功率!
 ⟹ 恒等式说: 油门控制的是【总能量率】 —— 高度与速度的能量之和。

 第三步: 能量在"动能⇄势能"之间的分配交给升降舵
    定义能量分配率:    ΔĖ/m = V·V̇ − g·ḣ        (动能率 − 势能率)
    物理意义: 升降舵改变俯仰角→改变 γ→决定"能量往动能还是势能搬"
    解耦的钥匙: ΔĖ 与 Ė 正交 —— 一个管"总量", 一个管"分配", 天然解耦!

 ⟹ 控制律结构 (两个 PI, 各管一个能量通道):
    油门 δ_T ← PI( Ė_des − Ė )      总能量率误差 → 油门
    俯仰 δ_E ← PI( ΔĖ_des − ΔĖ )    能量分配率误差 → 俯仰
    其中 Ė_des = V·V̇_des + g·ḣ_des,  V̇_des 与 ḣ_des 分别由空速误差/高度误差的比例环节生成

 直觉验证(为什么爬升不减速也无需"抢舵"):
    等能量爬升(动能→势能, 推力不变): V·V̇ < 0, g·ḣ > 0, 两者之和 ≈ 0
    → 总能量通道(油门)看到误差 ≈ 0, 油门不动 ✔
    → 分配通道看到 V·V̇ − g·ḣ < 0 (能量在向势能搬), 俯仰自动保持爬升姿态 ✔
    而传统双 PID 在同一场景里: 高度误差要拉杆, 空速下降要推油门+推杆, 三者耦合振荡。

7.6 TECS 参数体系与无空速降级

参数 数学角色 调参现象
FW_T_CLMB_MAX / FW_T_SINK_MAX 期望爬升/下沉率的饱和上限——决定 Ėdes 的最大值 爬不上去：CLMB_MAX 超过飞机实际爬升能力（或油门已饱和）
FW_T_TIME_CONST 外环一阶时间常数——能量环的名义带宽（≈长周期模态的阻尼来源） 高度/速度缓慢起伏（phugoid 不收敛）→ 减小；响应迟钝 → 增大
FW_T_SPDWEIGHT 空速误差与高度误差在两通道间的分配权重（0~2）——本质是两通道耦合矩阵的调度 =1 时空速优先均衡；空速保持不住 → 增大；高度跟不上 → 减小
FW_T_VERT_ACC 垂直加速度限幅——限制 ḣdes 的变化率（保护机体/防失速） 大油门猛拉抬头导致瞬时失速 → 减小
FW_T_* 油门限幅/俯仰限幅组 执行器饱和面（与抗积分饱和联动） 见 6.2 节 back-calculation

两个工程要点：其一，TECS 的能量通道需要空速信息，空速计失效时自动降级为「无空速模式」——用油门位置与俯仰角的静态映射推算空速（全权重退化，性能明显打折，长周期阻尼变差），这是固定翼空速计被视为「准必需传感器」的原因；其二，TECS 的饱和面（油门/俯仰极限）与失速保护在同一个框架内——能量需求超限时优先保空速（FWT_SPDWEIGHT），从能量视角看，「失速」就是动能被强制下限的约束优化。

本章一句话总结：L1 把「侧向位置控制」翻译成几何上自洽的滚转指令（固定阻尼 0.707 的二阶跟踪）；TECS 把「纵向双变量控制」翻译成能量守恒下的两个正交通道（油门管总量、俯仰管分配）。两者都不是普通的 PID 堆叠——理解推导之后，所有 FW_L1/NPFG/FW_T_ 参数都不再是魔法数字。

8. PX4 软件架构：NuttX、uORB 与 MAVLink

前六章是「算法」，本章是「算法住的房子」。PX4 的工程价值在于把每个算法做成独立模块，模块之间用消息总线通信——读源码、移植平台、替换算法都因此成为局部手术而非全局重构。

8.1 NuttX 实时操作系统

概念 内容 飞控意义
POSIX 接口 设备是文件（open/read/ioctl），进程/线程模型与 Linux 同构 同一套代码可在飞控板（NuttX）与仿真机（POSIX/Linux）编译——SITL 的基础
任务与优先级 抢占式实时调度，μs 级延迟确定 角速率环等高频任务绝不被低频任务阻塞

8.2 uORB：发布/订阅消息总线

uORB 是 PX4 的神经系统：每个数据类型是一个 topic（在 msg/*.msg 定义，构建期生成 C 结构体与元数据），发布者写入最新样本，订阅者按需读取，双方完全解耦——发布者不知道也不关心谁在读。

 关键性质:
 · 单写多读, "最新值"语义: 订阅者读到的是最近一次发布的完整样本(非队列) —
   控制环的每周期状态快照正是这个语义
 · 时间戳贯穿一切: 每条消息带 hrt_abstime 单调微秒时间戳 (EKF 对齐的依据, 3.6 节)
 · 多实例: 同一 topic 可有多份(如三颗 IMU 各一个 sensor 实例), 用实例索引区分
 · C++ 封装: uORB::Publication<topic> / uORB::Subscription + SubscriptionCallback(回调驱动)

 固定翼控制链的关键 topic (读源码的地图, 见 0.2 节数据流):
   sensor_combined → ekf2 → vehicle_attitude / vehicle_local_position / wind
   position_setpoint_triplet(navigator) → vehicle_attitude_setpoint(fw_lateral_longitudinal_control
                          → fw_att_control → fw_rate_control) → actuator_servos/actuator_motors

8.3 模块框架与 Shell

每个模块继承统一的框架：任务入口（task_spawn）、主循环或回调、控制台命令（start/stop/status/test）。在 NuttX shell（QGC MAVLink 控制台或串口）里可以像 Linux 一样操作：ekf2 status 看滤波器状态、param show FW_L1* 查参数、listener vehicle_attitude 实时打印任意 topic——listener 是联调时最快的探针，一行命令确认数据链路是否打通。

8.4 参数系统

参数是调参与标定数据的载体（ thousands 个，含每 IMU 的校准组）。定义走 module.yaml 声明式（类型/默认/范围/分组/重启依赖），运行时 RAM 影像 + 掉电持久化（Flash/FRAM）。工程纪律：一切可调数值走参数而不是宏——日志里能还原参数历史，Flight Review 才能追溯「那次飞行为什么不一样」。

8.5 MAVLink 通信协议

 MAVLink v2 帧结构:
 ┌────┬─────┬─────┬──────┬───────┬───────┬─────────┬─────────┬─────────┬─────────┐
 │STX │ LEN │ INC │ CMP  │  SEQ  │ SYSID │ COMPID  │ MSGID   │ PAYLOAD │ CHECKSUM│

8.6 日志与 ULog

logger 模块把订阅的 topic 流写入 ULog 格式（二进制：头部定义消息 + 帧数据消息 + 参数/追加段）。配套生态：Flight Review 自动生成飞行报告（姿态跟踪误差、EKF 一致性、振动谱、能量曲线——每张图对应一章的算法健康度）；replay 模块用日志中的原始传感器输入离线重跑 EKF——确定性复现，是调 EKF 参数唯一严谨的方法（改参数后对比同一份输入下的输出）。

8.7 控制分配：从力矩指令到舵机

上层给的是「期望力矩/归一化控制」，落到具体舵机要经过分配矩阵（v1.14 的 control_allocator 模块）。数学上是一个线性方程组 + 约束优化：

 W·v = u    v: 舵面偏转向量(副翼/升降/方向/油门), u: 期望控制(滚转/俯仰/偏航力矩+推力)
 固定翼的 W 由几何确定(舵面力臂/效率), 行满秩 → 最小二乘解即可;
 多执行器冗余(如 V 型尾双舵+方向舵)时取加权最小二乘 v = (WᵀW)⁻¹Wᵀu, 权重体现舵面效率与限幅偏好
 工程配置: 机体几何类型(AETR/V尾/飞翼) → 舵面混控关系; 校正方向与行程(PWMS_* 参数)

9.2 配置与校准流程（顺序不可乱）

  1. 刷固件 + 选机体配置（airframe，决定混控/默认参数/模块集）。
  2. 传感器校准：水平放置 → 罗盘（3.3 节球面拟合）→ 加计六面（3.2 节）→ 陀螺（上电静置）。看校准质量指标（残差），不看「显示成功」。

  5. SITL 仿真全流程彩排：任务上传 → 自动起飞 → 巡航 → 降落，把要在真机做的每个动作在仿真里走一遍。

航向缓慢漂移/盘旋不回 罗盘干扰或磁偏角未配、GPS/磁一致性失败 通电对比断电磁航向（3.3 节）；查 EKF 磁融合日志
空速读数异常（偏大/冻结/飞涨） 管路漏气/堵塞、动压孔朝向错误、结冰 地面静压检查；对比 GPS 地速+风速估计（3.5 节降级逻辑）
EKF 姿态机动时滞后 时间戳错位、IMU 滤波过重 查驱动时间戳（3.6 节）；放宽陀螺低通/陷波配置

10. 导航与任务：飞行模式、航点与起降

10.1 commander 与飞行模式状态机

commander 模块是全机状态机：解锁/上锁、飞行模式裁决（遥控、地面站指令、失控保护的优先级与抢占）、安全状态仲裁。固定翼主要模式：手动（manual/stabilized）、定高（altitude）、定点（position，需 GPS）、自动任务（mission）、盘旋（loiter）、返航（RTL/return）、自动起飞（takeoff）/降落（land）。模式切换的合法性检查（EKF 收敛、GPS 精度、位置有效）全部建立在第 5 章的估计质量门槛上。

10.2 mission 与 loiter 的几何

navigator 把任务航点序列翻译成制导层指令。转弯行为值得注意：到达判据不是「飞过点」而是按转弯半径提前转向（mission item 的接受半径 + 航迹切换几何），现代版本用「曲率连续」的路径平滑避免急转弯。盘旋是圆轨迹跟踪：半径 R、速度 V 时所需滚转角恒定：

 盘旋滚转角: φ = atan( V² / (g·R) )
 例: V=20 m/s, R=80 m → φ = atan(400/785) ≈ 27°
 风中盘旋: 无人机相对空气沿圆飞, 但地迹被风拉成"蜗牛线" → 制导律按地迹修正,
 NPFG 显式用风速估计保证地迹为圆(7.4 节), 这是风里盘旋轨迹的关键。

10.3 自动起飞与降落

自动起飞：滑跑阶段锁方向（地面转向舵），速度达到 FWTKOFF 空速后阶梯抬前轮、以限制坡度爬升到起飞高度。核心保护是「升空判据」：未达到最小爬升空速前禁止大迎角——防止低速拉飘失速。

自动降落是固定翼最危险的自动阶段，逻辑分四段：进近（对正跑道，航向制导）→ 下滑（恒下滑道，TECS 控能量）→ 拉平（flare）：到达 flare 高度（FWLND_FLALT）后俯仰目标上抬、油门收至怠速，以 恆定下沉率衰减的数学思想耗散下沉能量 → 接地（锁俯仰/收舵面）。flare 的触发高度取决于当时下沉率与空速——教材经典结论：接地前必须有速度/能量余量，风大时提前 flare；这些参数（FWLND_ 系列）务必在仿真与低空试飞中逐级验证。

10.4 定位源与降级链

导航层不关心定位来自哪里，只消费 EKF 的输出；EKF 按 5.5 节的门槛管理数据源切换：GPS（户外标准）→ 光流+测距（室内低空）→ 外部视觉/动捕（实验场）。固定翼最常见的降级是「GPS 短暂失效」：EKF 靠 IMU+空速+气压继续积分（误差随时间发散），此时禁止进入需要位置闭环的模式——commander 的检查项与 5.6 节的一致性检验是同一套数学。
